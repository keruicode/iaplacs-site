# IAP-LACS 预报网站

`iaplacs.xyz` 是一个 GitHub Pages 静态预报网站。页面与预报清单存放在本仓库，图件由两套数据源提供：**寰**（原 IAP 侧发布链路）和 **天河**（当前主用链路）。

当前四个页面均强制优先显示天河数据：

- `/`、`/ningxia/`：宁夏 `WORK_nx`；
- `/airpots/`：云南机场 `WORK_yn`；
- `/shangrao/`：上饶 `WORK`。

日常运行、检查、故障定位和手动切换方法见 [寰与天河运行维护手册](docs/寰与天河运行维护手册.md)。

本地预览：

```bash
python3 -m http.server 5173
```

访问 `http://127.0.0.1:5173/`；不要直接以 `file://` 打开页面。

本地改网页或文档时，只提交明确修改的文件。不要使用 `git add .`，也不要提交由服务器生成的预报图目录。
