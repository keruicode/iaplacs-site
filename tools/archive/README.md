# 历史脚本

这里保存退出当前生产链路的源文件，内容未修改，不应直接加入定时任务。

- `tianhe-transition/`：2026年7月天河临时发布、账号迁移、旧全国/上饶独立绘图及相关工具，共14个文件。
- `one-off/`：2026-09-13定时切换脚本、早期航空气象试验包装器，共2个文件。
- `iap-legacy/`：寰生产目录退役脚本的原样快照，不参与定时发布。
- `.runtime-snapshots/`：以前排障时下载或修改的脚本快照，仅本地保留，Git 忽略。

这些历史源码保留了当年的 `SCRIPT_DIR`、`tools/` 和服务器路径。
需要重用时，应先在隔离副本中把所需文件恢复到原 `tools/<同名文件>` 位置，并补齐共享脚本、SHP 和运行环境，再测试；不要直接从归档目录执行。
尤其不要运行一次性切换脚本，它可能把当前网页恢复成旧版本。

当前生产目录和 crontab 没有随本地整理迁移。恢复旧天河服务属于单独部署任务，不能仅凭这些归档文件自动恢复。
